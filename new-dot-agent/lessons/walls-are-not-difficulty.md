# walls-are-not-difficulty

**A test ~every gate-population agent fails is a WALL, not difficulty — the fingerprint is castor
0/N while rollouts stay ~1.0. Remove the wall and restore the prior state byte-exact from git.**

## Evidence (as of 2026-06-10)
- `java-semantic-tokens` iter-4: a description de-telegraph (hiding the type-position enumeration)
  → castor 0/10. Categorizing the batch showed the de-telegraph alone erased the band.
- `java-semantic-tokens` iter-6: an anonymous-class-supertype dedup fork → castor 0/12 (the anon
  test failed 12/12; two agents failed ONLY it) while diamond rollouts were 3/3 = 1.0 — the
  unsolvability-wall fingerprint in its purest form.
- Recovery both times: remove the wall lever and restore the previous deliverable byte-exact from
  git history (never hand-revert — drift creeps in).
- Corollary: difficulty is not linear in explicitness; one removed enumeration flipped 5/10 → 0/10.
  Move one lever at a time and re-measure.

## Applies at
W5 §1 (the 0/N + ~1.0 row) and any description-lever decision.
