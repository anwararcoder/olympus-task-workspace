# leaf-value-arithmetic

**A leaf-shaped feature caps the maximum failure cascade, and one hour of arithmetic at plan time
proves whether the partial-reward bar is even reachable — secret-rotation's revert was computable
five weeks before it happened.**

## Evidence (as of 2026-06-10)
- `osctrl-secret-rotation-windows`: the enrollment secret is a leaf value (no derived state, no
  cache, no downstream consumers). Its dominant failure cluster (zero-grace semantics) gated ~5 of
  35 tests; the union of EVERY historically-observed cluster was 10/35. Under partial reward the
  weakest plausible strong agent still scored ~0.71 and the median ~0.87 — the <0.6 bar was
  mathematically unreachable by any fair lever. The task was nonetheless finalized, then reverted
  on 3x 1.00 rollouts.
- The same arithmetic run on `jte-precompile-maintenance` at W1 (2026-06-11) PASSED it in an hour:
  fresh-engine score geometry makes the in-memory shortcut fail ~53% of the sketched suite.

## Applies at
W1 Gate A (mandatory cascade arithmetic before any build) and W5 §2 (re-run on measured clusters).

## Rule it shaped
`rules/idea-crafting.md` Gate A, `rules/task-shape.md` §2 (score geometry).
